# Gem Mint or Bust

A browser giveaway game. Every entrant gets a card-grading line: cards are inspected, graded, slabbed and checked. Each Gem Mint 10 earns a capsule in the claw machine, and the claw then draws the winners. More capsules means better odds.

**Play it:** https://beezie.mew.cards/

The page also has a second tab, **Wheel of Beezie** (https://beezie.mew.cards/#wheel): a spinning wheel of names that picks one at random and can record a video of the spin.

The whole game is the single file `index.html`, with no build step and no dependencies apart from Google Fonts. To run it locally, open `index.html` in a browser.
